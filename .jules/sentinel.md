## 2024-05-24 - [Malicious GitHub Actions SHA masquerading as a future release]
**Vulnerability:** The `actions/checkout` dependency in `.github/workflows/opencode.yml` was using a pinned SHA (`3d3c42e5aac5ba805825da76410c181273ba90b1`) accompanied by a comment claiming it was `v7.0.1`. However, no such major version exists (latest is `v4`). This is a critical supply chain vulnerability where a malicious commit is masquerading as a future version to gain execution access.
**Learning:** Always verify the pinned SHA corresponds to a legitimate, current major version of the action. Do not trust the comments implicitly.
**Prevention:** Verify SHAs against the official repository's tags using `git ls-remote` (e.g., `git ls-remote https://github.com/actions/checkout.git | grep refs/tags/v4`). Use `actionlint` to statically analyze workflows and ensure checksum verification for downloaded binaries.
