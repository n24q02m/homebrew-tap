## 2024-06-03 - CI/CD Resource Exhaustion Prevention
**Vulnerability:** The GitHub Actions workflow `opencode.yml` did not define job timeouts. The default timeout for GitHub Actions is 6 hours. Since this workflow uses an external LLM service (`anomalyco/opencode/github`), an attacker could potentially craft complex or adversarial inputs (or the external API could simply hang), causing the job to run indefinitely. This could lead to a Denial of Service (DoS) by exhausting the organization's GitHub Actions concurrency limits or billed minutes.
**Learning:** External API dependencies in CI/CD pipelines introduce a risk of jobs hanging or taking excessive time, particularly when processing untrusted input that can trigger complex operations. Relying on the default 6-hour timeout is unsafe.
**Prevention:** Always enforce strict `timeout-minutes` (e.g., 10-15 minutes) on all GitHub Actions jobs, especially those interacting with third-party APIs or processing user-submitted content. This follows the "fail securely" principle by ensuring runaway processes are terminated.
